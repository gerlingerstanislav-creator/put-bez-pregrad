# Путь без преград

Отдельный публичный лендинг услуги перевозки людей на инвалидных колясках в Ульяновске и Ульяновской области.

Сайт собирается с помощью Vue 3 + Vite и публикуется на виртуальном хостинге Timeweb через GitHub Actions (FTPS). Подробная документация и исходники добавляются в репозиторий.
