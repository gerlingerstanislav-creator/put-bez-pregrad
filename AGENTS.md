# Инструкции по сопровождению

- Это независимый Vue + Vite сайт с минимальным PHP 8.2 API без Laravel и базы данных.
- Главный источник пользовательского интерфейса — `src/App.vue`, компоненты — `src/components/`, фотографии и логотипы — `public/images/`.
- Проверяй сайт на desktop/mobile и работу ссылок tel:, mailto: и MAX.
- Перед изменениями `main` проверь текущий HEAD и файлы. Перед push: `npm run check && npm run build && node scripts/check-dist.mjs`.
- Обновляй README при изменении поведения, инфраструктуры или деплоя.
- Не добавляй ключи, пароли, токены или production-секреты в исходники и логи.
- Публикация через FTP порт 21 (обычный FTP без шифрования — ограничение виртуального хостинга). Для CI/CD использовать только отдельного FTP-пользователя с доступом к каталогу сайта; позже при появлении SSH рассмотреть безопасный SFTP. Публиковать только dist и не очищать хостинг целиком.
- Форма заявки отправляет через PHP mail() на email из настроек, текст заявки не хранится на сервере. Контакты и пароль редактируются в /admin/, состояние хранится в api/private/state.php и никогда не отслеживается Git. Проверяй PHP синтаксис и изоляцию приватных данных; пароль всегда хешировать password_hash(). При включении HTTPS защищать cookie флагом Secure и сбрасывать старые HTTP-сессии.
