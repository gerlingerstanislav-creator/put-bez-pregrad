# Инструкции по сопровождению

- Это отдельный статический Vue + Vite сайт, без Laravel и серверной базы данных.
- Главный источник пользовательского интерфейса — `src/App.vue`, компоненты — `src/components/`, фотографии и логотипы — `public/images/`.
- Проверяй сайт на desktop/mobile и работу ссылок tel:, mailto: и MAX.
- Перед изменениями `main` проверь текущий HEAD и файлы. Перед push: `npm run check && npm run build && node scripts/check-dist.mjs`.
- Обновляй README при изменении поведения, инфраструктуры или деплоя.
- Не добавляй ключи, пароли, токены или production-секреты в исходники и логи.
- Публикация через FTPS (TLS, проверка сертификата) только папки dist; не очищай удалённый хостинг целиком.
- Форма заявки открывает почтовый клиент, а не хранит данные на сервере.
